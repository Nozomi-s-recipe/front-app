# Nozomi's Recipes - 画面設計・ページ遷移ドキュメント

## 概要

レシピサイトの画面構成とページ遷移を定義したドキュメント。
実装時のAI参照用に最適化。

---

## ページ一覧

| ページ名 | URL | 説明 |
|---------|-----|------|
| トップページ | `/` | 新着・おすすめ・カテゴリ・クイックフィルター |
| カテゴリページ | `/japanese`, `/chinese`, `/mediterranean` | カテゴリ別レシピ一覧＋フル版フィルター |
| お気に入りページ | `/favorites` | 保存したレシピ一覧 |
| レシピ詳細ページ | `/recipe/{id}` | レシピの詳細情報 |

## コンポーネント別アクション一覧

### 共通ヘッダー

| 要素 | アクション | 遷移先 | 遷移タイプ |
|------|-----------|--------|-----------|
| ロゴ | タップ | `/` | ページ遷移 |
| ♡ お気に入りアイコン | タップ | `/favorites` | ページ遷移 |
| アバター | タップ | (未実装) | - |

### トップページ専用

| 要素 | アクション | 遷移先 | 遷移タイプ |
|------|-----------|--------|-----------|
| 検索バー | Enter | - | その場で絞り込み |
| カテゴリカード | タップ | `/japanese` 等 | ページ遷移 |
| 「すべて」リンク | タップ | - | その場で展開 |
| クイックフィルターチップ | タップ | - | その場で絞り込み |
| 「詳細検索→」 | タップ | - | ボトムシート/モーダル |
| 今日のおすすめカード | タップ | `/recipe/{id}` | ページ遷移 |

### カテゴリページ専用

| 要素 | アクション | 遷移先 | 遷移タイプ |
|------|-----------|--------|-----------|
| ← 戻るボタン | タップ | 前のページ | 履歴back |
| パンくず「トップ」 | タップ | `/` | ページ遷移 |
| フィルターチップ | タップ | - | その場で絞り込み |
| 「クリア」ボタン | タップ | - | フィルターリセット |
| ページネーション | タップ | `?page=N` | ページ遷移 |

### レシピカード（共通）

| 要素 | アクション | 遷移先 | 遷移タイプ |
|------|-----------|--------|-----------|
| カード全体 | タップ | `/recipe/{id}` | ページ遷移 |
| ジャンルタグ | タップ | `/japanese/rice` 等 | ページ遷移 |
| ♡ ボタン | タップ | - | お気に入り追加（遷移なし） |

### 詳細検索（ボトムシート/モーダル）

| 要素 | アクション | 遷移先 | 遷移タイプ |
|------|-----------|--------|-----------|
| オーバーレイ | タップ | - | シート閉じる |
| ✕ 閉じるボタン | タップ | - | シート閉じる |
| フィルターチップ | タップ | - | 選択切り替え |
| 選択タグの✕ | タップ | - | そのフィルター解除 |
| 「リセット」 | タップ | - | 全フィルター解除 |
| 「レシピを見る」 | タップ | - | シート閉じる＋絞り込み適用 |

## URL設計

### 基本URL

```
/                        # トップページ
/japanese                # カテゴリページ（和食）
/chinese                 # カテゴリページ（中華）
/mediterranean           # カテゴリページ（地中海）
/western                 # カテゴリページ（洋食）
/dessert                 # カテゴリページ（デザート）
/favorites               # お気に入り
/recipe/{id}             # レシピ詳細
```

### クエリパラメータ

```
?page=2                  # ページネーション
?time=15                 # 調理時間フィルター（15分以内）
?genre=rice              # ジャンルフィルター
?ingredients=5           # 材料数フィルター（5個以下）
```

### フィルター適用時のURL例

```
/japanese?time=15&genre=rice&ingredients=5&page=1
```

## 補足

### 遷移タイプの定義

| タイプ | 説明 |
|--------|------|
| ページ遷移 | URLが変わる。ブラウザ履歴に追加 |
| その場で絞り込み | URLは変わらない（またはクエリパラメータのみ変更）。画面遷移なし |
| ボトムシート/モーダル | オーバーレイ表示。URLは変わらない |
| 履歴back | `history.back()` で前のページに戻る |

### フィルターの動作

- **トップページ**: クイックフィルターはその場で絞り込み。「詳細検索→」でボトムシート表示
- **カテゴリページ**: フル版フィルターが常時表示。選択するとその場で絞り込み
- **フィルター適用時**: URLにクエリパラメータを付与（共有可能にするため）
